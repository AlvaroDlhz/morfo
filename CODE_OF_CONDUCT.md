# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todo el mundo con respeto, critica las ideas y no a las
personas, acepta las opiniones distintas y ayuda a que quien llega por
primera vez se sienta bienvenido. No se toleran el acoso, los insultos ni los
ataques personales, ni en *issues*, PR o *Discussions* ni fuera de ellos
cuando afecten a la comunidad.

## Cómo informar

Si ves o sufres un comportamiento inaceptable, escribe a las personas
responsables del proyecto por un canal privado (por ejemplo, abriendo un
aviso de seguridad privado en la pestaña *Security* de GitHub). Toda
denuncia se revisará con confidencialidad.

Quien incumpla el código puede recibir un aviso, una expulsión temporal o una
expulsión permanente del proyecto, según la gravedad.
